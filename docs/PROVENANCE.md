# Provenance and license

MIT was selected by the project owner. The LICENSE covers this project's distributed Python source and documentation. Source was recovered from the owner's existing project and extended for standalone distribution; the DES algorithm was retained and its worker input is passed through a private inherited file descriptor.

Protocol formats were checked against the supplied IPC360 Home8.10.1.0 application. No APK, DEX, proprietary SDK binary, native shared library, captured session or video recording is distributed. Python modules with native in their names implement the recovered DES operations in Python; the runtime does not import an SDK, ctypes or Unicorn.

Home Assistant, FFmpeg, PyAV and test dependencies are separately installed software with their own licenses. They are not vendored or relicensed by this repository. No affiliation with or endorsement by the camera vendor is claimed.

Private development archives and detailed operational history are not part of this repository. Live verification is summarized using counts only. Historical research tests remain in the private project archive; current runtime tests are distributed here and run independently of that archive.
