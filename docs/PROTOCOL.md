# Protocol scope

NET V2 email/password authentication creates a fresh128-byte session and canonical account identity. Device discovery queries owned and shared groups separately. Shared playback identity comes from fresh metadata; it does not replace the current account identity used by manager authentication.

The manager endpoint comes from fresh login. Device routing derives the father identifier from the current device-state response. Relay negotiation advertises the process's own route-local address and ephemeral UDP port, not captured addresses. Media is correlated to the selected device and relay. Bounds and deadlines apply to framing, handshake, media and downstream writes.

Video is passed to the recovered pure Python DES worker, then remuxed as HEVC MPEG-TS. Optional G.711 A-law8kHz mono audio is encoded as AAC. Worker key input travels over a private inherited descriptor; it is not put in argv, the environment or a temporary credential file.

The independent fresh-session shared-device route was accepted by the real service and decoded HEVC/AAC. This does not prove every model or network variant. No loss recovery, reorder buffer or CN carrier policy is claimed. Future protocol corrections should use fresh responses and explicit evidence rather than historical packet templates.
